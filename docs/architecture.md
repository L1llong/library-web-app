# Архитектура системы — АИС «БиблиоКонтроль»

## Схема архитектуры

Ниже представлена схема взаимодействия компонентов разрабатываемой информационной системы.

```text
┌─────────────────────┐         ┌─────────────────────┐         ┌─────────────────────┐
│                     │  HTTP   │                     │  SQL    │                     │
│   Vue 3 + Vite      │ ──────► │   ASP.NET Core      │ ──────► │   PostgreSQL        │
│   (Клиент)          │         │   (Сервер)          │         │   (База данных)     │
│   localhost:5173    │         │   localhost:5000    │         │   порт: 5432        │
│                     │         │                     │         │                     │
└─────────────────────┘         └─────────────────────┘         └─────────────────────┘
```

архитектура web-ИС семестра

## Описание узлов
1. Vue 3 + Vite (порт 5173): Клиентская часть. Отвечает за отрисовку пользовательского интерфейса (экраны списка заявок, создания заявки, входа в систему) и отправку HTTP-запросов на сервер. Не имеет прямого доступа к базе данных. 
2. ASP.NET Core (порт 5000): Серверная часть (Backend). Принимает HTTP-запросы от клиента, проверяет бизнес-правила (валидация, права доступа, статусы), формирует SQL-запросы и возвращает клиенту ответ в формате JSON. Является единственным источником правды о данных. 
3. PostgreSQL (порт 5432): Система управления базами данных. Хранит сущности BookRequest, Book и User в нормализованном виде (3НФ). Отвечает только на запросы от сервера ASP.NET Core.

## Пример запроса
**Действие: Создание новой заявки на выдачу книги.**

Метод: POST

Путь: http://localhost:5000/api/requests

Тело запроса (JSON):
```
   {
     "title": "Война и мир",
     "bookId": 5,
     "description": "Нужна для курсовой по литературе"
   }
```

Код ответа: ``201 Created``

Тело ответа (JSON):
```
   {
     "id": 17,
     "number": "REQ-2026-042",
     "status": "New",
     "bookId": 5,
     "assigneeUserId": null
   }
```
